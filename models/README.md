# 한반도 디오라마 모델 (korea.glb)

`diorama.html`이 이 폴더의 `korea.glb`를 불러옵니다. 파일이 없으면 임시 섬이 대신 나옵니다.
다른 파일을 시험하려면 `diorama.html?model=models/다른이름.glb`.

## 지켜 주면 좋은 약속

- 형식: glTF 바이너리(.glb). Draco 압축 OK. 10MB 이하 권장.
- 축: 블렌더에서 Z가 위, +Y가 북쪽으로 만들고 glTF 내보내기 기본값(+Y Up)으로 내보내기.
- 크기: 1 unit = 1 km. 원점은 경도 127.8°, 위도 35.9°. 높이는 과장해도 됨.
- 재질: 실제 색을 넣어 둔 PBR(Principled BSDF). 조명은 페이지가 넣으니 모델에 램프는 넣지 않기.

## 오브젝트 이름 (중요)

| 이름 | 무엇 |
|---|---|
| `island` | 지형+흙 단면 덩어리. 그림자를 받음 |
| `site_bohyeon_obs` | 보현산 천문대 위치 (빈 오브젝트나 미니어처) |
| `site_bohyeon_sci` | 보현산 천문과학관 |
| `site_uiseong` | 의성 달빛공원 |
| `site_gajisan` | 가지산 |
| `site_kmu` | 계명대학교 |
| `trees`, `props` 등 | 자유. 그림자를 드리움 |

`site_*` 오브젝트가 2개 이상 있으면 페이지가 그 위치를 기준으로 좌표를 자동 보정합니다.
그래서 축척이나 원점이 조금 달라도 구름과 점수 표시가 제자리에 붙습니다.
`site_*`가 하나도 없으면 섬 전체 크기를 남한 범위에 맞춰 대충 맞춥니다.

페이지가 얹는 것: 구름(예보 격자), 달과 달빛, 해질녘 하늘색, 별, 관측지 등불과 점수.
